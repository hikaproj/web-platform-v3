# AI向け: ツールページ雛形の使い方

このフォルダーは、Hikaproj Web Platform v3 の共通デザインを使って、新しいWebツールを実装するための開始点です。特定ツールの画面やロジックではなく、共通ページ枠・空のツール領域・再利用できる入力/ボタンの基本スタイルを含みます。

## 必ず最初に読む

1. このガイドを読む。
2. 親フォルダーの `../AGENTS.md`、`../DESIGN-MANUAL.md`、`../components.html` を確認する。特に `../AGENTS.md` の共有ヘッダーを変更しない規則に従う。
3. 実装要求に必要な機能・入力・結果・エラー状態だけを作る。不明な仕様をデモ機能で埋めない。
4. このフォルダーを新しいツールの配置先へ複製し、ページ内容と機能を複製先だけで変更する。

## 雛形に含まれるもの

- `index.html`: Hikaprojロゴ、共通ヘッダーとナビゲーション、ページ見出し、ツールUIの差し込み領域、ツール一覧へ戻るリンク、フッター。
- `style.css`: このテンプレート内で完結するデザイン、レスポンシブ規則、基本的なフォーム/ボタン/状態用クラス。
- `script.js`: モバイル用の共通ナビゲーションだけを実装。ツール機能の処理は含めない。

ロゴ画像のみ `https://hikaproj.com/new/512.hikaproj.logo.png` から取得します。その他のCSS、JavaScript、アイコンは外部依存にしません。

共通ヘッダーは Hikaproj のサイト導線とブランドを維持するための固定要素です。ロゴ、リンク先、ナビゲーション文言、シェアアイコン、モバイルメニューのマークアップ/CSS/JavaScriptは変更せず、テンプレートからそのまま引き継いでください。

## 新しいツールにする手順

1. `index.html` のtitle、description、`page-code`、h1、説明文、装飾アイコンを実際のツールに合わせる。
2. `.tool-content-placeholder` を削除し、その位置へ目的に合ったツールUIを実装する。空のスロットはパスワード生成UIを意味しない。
3. 必要に応じて `.tool-card`、`.tool-section-title`、`.tool-description`、`.tool-field`、`.tool-input`、`.tool-select`、`.tool-textarea`、`.tool-check`、`.tool-actions`、`.tool-button`、`.tool-status` を利用する。
4. UIだけでなく、要求された処理、入力検証、成功/失敗表示、キーボード操作を実装する。未依頼の機能やサンプル操作は追加しない。
5. 機能処理は `script.js` に追加する。既存のヘッダーメニュー処理を維持し、初期化とイベントの対象要素がないページでもエラーにならないようにする。
6. 通信、保存、権限、外部API等が必要な場合は、ユーザー要求と既存プロジェクトの仕組みを確認する。セキュリティやプライバシー上の性質を推測して断定しない。
7. 戻り先をサイトの実際の構成に合わせ、必要なら `https://hikaproj.com/new/works/` から適切な一覧へ変更する。

## 維持する共通デザイン

- 背景 `#101311`、文字 `#eaf0e9`、補助文字 `#a3aea4`、ライム `#c6ff53`、シアン `#66dcff`、注意 `#ff775b`。
- 細い境界線、控えめなグラデーション、過度な角丸や影を使わない。
- PCではコンテンツ最大幅1120px。620px以下ではヘッダーメニューを開閉式にし、入力・操作は縦に並べる。
- ラベルを入力へ関連付ける。アイコンだけのボタンには明確な `aria-label` を付ける。
- 動的メッセージは `role="status"` または適切なlive regionで通知し、失敗時に成功表示をしない。
- `prefers-reduced-motion` とfocus-visibleを維持する。色だけで状態やフォーカスを表現しない。

## 雛形から持ち込まないもの

- `tools/passgen` のパスワード生成フォーム、文字種チェック、文字数スライダー、強度メーター、生成/コピー/表示処理。
- 元ツール固有の説明、SEO文言、データ、API、依存ライブラリー。
- 実際に動かない操作を成功したように見せるダミー機能。
- 利用者の指示にない外部通信・データ保存・追加権限。

## 仕上げの確認

- 320px、360px、620px、desktopでページ全体の横はみ出しがない。
- マウスだけでなくTab/Shift+Tab、Enter/Spaceで操作できる。
- 入力値・境界値・空値・エラー・処理中・成功状態を検証する。
- ブラウザーコンソールに例外がなく、外部リソース依存が要求どおりである。
- 変更したUI・動作に合わせてこのファイルとページの説明を更新する。
