# Hikaproj Web Platform v3

Hikaproj Web Platform v3 の共通デザインシステムです。Webサイト、アプリケーション、ツール、記事など、用途の異なるページで視覚言語と操作ルールを共有します。

## 内容

| ファイル | 用途 |
| --- | --- |
| `index.html` | デザインシステムの概要 |
| `components.html` | 共通UIパーツの実装例 |
| `style.css` | デザイントークン、共通スタイル、レスポンシブ規則 |
| `script.js` | ナビゲーションやコンポーネント見本の動作 |
| `DESIGN-MANUAL.md` | デザイン仕様と実装ガイド |
| `tool-template/` | 新しいツールページの雛形とAI向けガイド |
| `AGENTS.md` | このデザインを使ってページを制作・変更する際の必須指示 |

## 利用方法

ページを新規作成・変更する前に、まず `AGENTS.md` を確認してください。デザイントークンやコンポーネントの詳細は `DESIGN-MANUAL.md`、具体的な見た目とマークアップは `components.html` を参照します。

ツールページを作る場合は `tool-template/` をコピーして使用し、`tool-template/AI-TOOL-GUIDE.md` に従ってください。共通ヘッダー、フッター、ナビゲーションなどの必須ルールは `AGENTS.md` を正とします。

## 基本方針

- ページの目的に合わせて構成を選び、共通の視覚言語と操作性を保ちます。
- キーボード操作、フォーカス表示、レスポンシブ対応、支援技術への情報提供を維持します。
- 共通デザイン自体の変更を依頼された場合を除き、共通ファイルをページ固有の都合で変更しません。
